Fraud & duplicate-risk orders

Exchange orders — no extra profit

Why flag these

An exchange replaces the item at no additional charge — you re-ship a product for the same original order value, so there's no incremental profit and you absorb the extra shipping/packing cost. Cancelling ones you can't fulfil profitably is often the better call.

Exact panel path to cancel/reject an exchange

  1. If the exchange hasn't been accepted/packed yet: Supplier Panel → Orders → Confirm & Pack tab → find the sub-order number → click "Reject Item" → pick a reason from the dropdown (e.g. "Not fulfillable") → click "Confirm Cancellation".
  2. If it already shows as a return/exchange request: go to the Returns tab → open the matching sub-order → you'll see Approve / Reject — choose Reject and enter the reason (this gets shown to the customer automatically).
  3. If neither option is available for that order's current status: go to Support (left sidebar) → Help tab → category "Returns/RTO & Exchange" → select the closest matching issue (e.g. "I want to cancel/reject a return or exchange") → submit with the sub-order number in the description. Track it under the "My Tickets" tab.
  4. Use this selectively — frequent cancellations can affect your seller rating, so reject only exchanges that would genuinely run at a loss.

These tab names are current as of Meesho's own seller Learning Hub, but panels get updated — if wording doesn't match exactly, use the Help tab's search to find the closest option.

There's no verified public dataset mapping Indian states to exact shoe/clothing size differences — the CSIR-CLRI national foot survey confirmed regional variation exists, but the size-conversion numbers aren't public yet.
